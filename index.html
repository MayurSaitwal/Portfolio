03 — Projects

Hands-on Cloud & DevOps projects

Three projects covering Kubernetes on AWS, infrastructure as code, and automated delivery with monitoring. Each links to its source on GitHub.

  • 01 AWS · Kubernetes

    Three-Tier Application on AWS EKS

    A React, Node.js and MongoDB app containerized with Docker, stored in Amazon ECR and run on Amazon EKS with Deployments, Services, Secrets and a PV/PVC for MongoDB. The AWS Load Balancer Controller, installed with Helm and IRSA, exposes it through an Ingress-backed Application Load Balancer.

    1. ALB
    2. Ingress
    3. React
    4. Node.js
    5. MongoDB

    Demonstrates: container registries, Kubernetes workloads, persistent storage, least-privilege access with IRSA, ingress routing.

    • AWS EKS
    • ECR
    • ALB
    • Helm
    • Docker
    • Kubernetes
    View Project : Three-Tier Application on AWS EKS (opens in a new tab)
  • 02 Infrastructure as Code

    Multi-Environment AWS Infrastructure with Terraform

    Replaces manual console work by provisioning isolated Dev, Staging and Prod environments on AWS from reusable Terraform code that defines EC2 instances and an S3 bucket. Each environment passes its own variables, and outputs print the values needed after deployment.

    1. Terraform code
    2. dev
    3. stg
    4. prd

    Demonstrates: modules, variables and outputs, provider version pinning, environment separation, the full init → plan → apply → destroy lifecycle.

    • Terraform
    • AWS EC2
    • AWS S3
    View Project : Multi-Environment AWS Infrastructure with Terraform (opens in a new tab)
  • 03 CI/CD · Observability

    End-to-End CI/CD Pipeline with Kubernetes Monitoring

    A Jenkins pipeline, triggered by GitHub webhooks, builds a Docker image, pushes it to Docker Hub, deploys a Flask and MySQL app to a Kind cluster and verifies the rollout. Prometheus and Grafana, installed with Helm in a dedicated monitoring namespace, give cluster-health dashboards.

    1. Git push
    2. Jenkins
    3. Docker Hub
    4. Kubernetes
    5. Grafana

    Demonstrates: pipeline as code, webhook-triggered builds, an SSH-connected Jenkins agent, Kubernetes Secrets and PVCs, cluster monitoring.

    • Jenkins
    • Docker
    • Kubernetes
    • Helm
    • Prometheus
    • Grafana
